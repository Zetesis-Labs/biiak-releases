ANTES DE EMPEZAR

Un par de cosas
que conviene saber.

Windows muestra «Windows protegió su PC»+

Ese mensaje de SmartScreen indica que Windows no reconoce la aplicación; no es, por sí solo, una detección de virus.

Si has descargado el instalador de este repositorio oficial, pulsa «Más información» y comprueba el archivo. Si aparece «Ejecutar de todas formas» y confías en su origen, puedes continuar sin desactivar Defender. Una política de tu organización puede impedirlo.

Si el antivirus identifica una amenaza o pone el archivo en cuarentena, no lo ignores: detén la instalación y consulta a la persona responsable de la prueba.

Información de Microsoft ↗
¿Qué significa que una versión sea alpha?+

Es una versión de prueba, no una entrega productiva. Utilízala exclusivamente con datos sintéticos: no introduzcas información real de personas o expedientes.

Las versiones alpha pueden contener errores. Cuando haya una versión estable, aparecerá como descarga principal; las pruebas seguirán identificadas por separado.

¿Cómo se comprueban las descargas y actualizaciones?+

Cada release incluye la firma del actualizador y el archivo SHA256SUMS. Biiak comprueba la firma antes de aceptar una actualización.

Esta firma no equivale a la firma de editor que reconoce Windows (Authenticode). Consulta las notas de cada versión para conocer su estado de firma.

¿Hay un instalador para Mac o Linux?+
